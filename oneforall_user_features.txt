ONEFORALL - DANH SACH CHUC NANG DANH CHO USER

Phạm vi: Chỉ bao gồm các chức năng dành cho người dùng thông thường, không bao gồm chức năng quản trị Admin.
Lưu ý: Danh sách được tổng hợp từ README và các API trong repository oneforall_be. Các tính năng phụ thuộc vào cấu hình backend hoặc cần kiểm thử thực tế được ghi chú rõ.

==================================================
1. VIDEO & AUDIO DOWNLOADER
==================================================
1. YouTube to MP4 - Tải video YouTube.
2. YouTube to MP3 - Trích xuất âm thanh YouTube sang MP3.
3. YouTube to WAV - Trích xuất âm thanh YouTube sang WAV (cần kiểm thử thực tế).
4. YouTube to AAC - Trích xuất âm thanh YouTube sang AAC (cần kiểm thử thực tế).
5. YouTube to M4A - Trích xuất âm thanh YouTube sang M4A (cần kiểm thử thực tế).
6. TikTok to MP4 - Tải video TikTok.
7. TikTok to MP3 - Trích xuất âm thanh TikTok sang MP3.
8. TikTok to WAV - Chuyển âm thanh TikTok sang WAV (cần kiểm thử thực tế).
9. TikTok to AAC - Chuyển âm thanh TikTok sang AAC (cần kiểm thử thực tế).
10. TikTok to M4A - Chuyển âm thanh TikTok sang M4A (cần kiểm thử thực tế).

API chính: POST /api/v1/media/process
Thao tác tải từ URL: operation=url_download, params.format chọn định dạng đầu ra.

==================================================

12. Video Compressor - Nén video, giảm dung lượng tùy thiết lập.
13. Video to MP3 - Tách âm thanh từ video sang MP3.
14. Video to WAV - Tách âm thanh từ video sang WAV.
15. Video to AAC - Tách âm thanh từ video sang AAC.

==================================================
5. FILE UPLOAD & DOWNLOAD
==================================================
46. Upload File - Tải file lên để xử lý.
47. Direct-to-Storage Upload - Upload trực tiếp lên R2 bằng presigned URL.
48. Download Converted File - Tải file kết quả đã xử lý.
49. Direct File Streaming - Tải file trực tiếp qua backend.
50. Direct Storage Download - Tải file qua presigned URL của storage.
51. Automatic Temporary File Cleanup - Tự động dọn file kết quả hết hạn theo chính sách backend.
52. Retry Download - Có thể thử tải lại nếu lượt tải trực tiếp bị gián đoạn và file vẫn còn.
53. Output Filename - Tạo tên file đầu ra phù hợp khi tải về.

API liên quan:
- POST /api/v1/files/presigned-upload-url
- POST /api/v1/files/presigned-download-url
- GET /api/v1/files/{job_id}/download
- POST /api/v1/files/{job_id}/consumed

Theo README, file kết quả có TTL mặc định khoảng 3 phút; cần thông báo người dùng tải kịp thời.

==================================================
6. JOB PROCESSING
==================================================
54. Background Processing - Xử lý file bằng hàng đợi nền.
55. Job Status Tracking - Theo dõi trạng thái tác vụ.
56. Job Progress Display - Hiển thị tiến độ nếu backend trả về thông tin tiến độ.
57. Job Completion State - Hiển thị khi xử lý hoàn thành.
58. Job Failure Handling - Hiển thị khi xử lý thất bại.
59. Result Download - Cho tải kết quả sau khi Job hoàn thành.

Trạng thái Job: queued, processing, completed, failed.
API theo dõi: GET /api/v1/jobs/{job_id}

==================================================
60. View Profile - Xem hồ sơ cá nhân.

- GET /api/v1/users/me

Đăng nhập, đăng ký và OAuth được xử lý qua Supabase Auth hoặc luồng xác thực hiện có; các endpoint hồ sơ bên trên không đại diện cho toàn bộ chức năng xác thực.
